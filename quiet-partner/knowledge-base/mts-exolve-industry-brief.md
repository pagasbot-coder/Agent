# МТС Exolve — industry brief (SME)

**Проект:** Проект МТС  
**Владелец:** SME (`@role-sme`)  
**Статус:** v0.1 черновик  
**Обновлено:** 2026-08-04  
**Дисклеймер:** полевые гипотезы для подготовки; даты НПА → Legal / юрист Exolve.

---

## 1. Контекст отрасли

Exolve продаёт B2B голос/SMS/API/8-800/ВАТС. Антифрод здесь — не «банковский скоринг», а **операторский/провайдерский контур**: сигналы, блокировки, обмен с ГИС, сохранение легального трафика клиентов.

**Не смешивать:** СОРМ (доступ УО) ≠ антифрод (ГИС, выявление/блокировка мошеннических коммуникаций).

---

## 2. Day-in-life (черновик)

| Персона | День | Где горит |
|---------|------|-----------|
| Антифрод-аналитик | Смотрит алерты FP/FN, разбор кейсов B2B, правки исключений | Ложные блокировки VIP-клиентов |
| B2B support | Тикеты «нас заблокировали», эскалация в продукт/ИБ | Нет runbook / долгий unblock |
| Сеть / телефония | CLI, транзит, маршруты 8-800, аномалии трафика | Подмена номера, серый транзит |

---

## 3. Hidden pains

| Боль | Проявление | Прокси-метрика |
|------|------------|----------------|
| False positive | Легальный клиент в блоке | FP rate, time-to-unblock |
| Задержка сигнала | Фрод уже «отстрелялся» | time-to-block / time-to-report |
| Путаница СОРМ/антифрод | Два контура в одном эпике | RACI / раздельные epic ID |
| ВАТС / облако | Учёт и ограничения по новым нормам | % ВАТС в gap matrix |
| API-ключи | Компрометация кабинета → исходящий фрод | incidents / revoked keys |

---

## 4. MUST KPI (прокси, X согласовать с бизнесом)

1. Доля обязательных интеграций/процессов к дате N (Legal)  
2. Uptime узла обмена с ГИС (DevOps)  
3. FP rate ≤ X%  
4. Time-to-block / time-to-report ≤ Y  
5. Time-to-unblock легального клиента ≤ Z  
6. 0 критичных предписаний по просрочке  
7. Runbook support готов до go-live  

---

## 5. Глоссарий (RU)

| Термин | Смысл |
|--------|--------|
| CLI | Calling Line Identity — отображаемый/передаваемый номер |
| ВАТС | Облачная/виртуальная АТС |
| ГИС «Антифрод» | Госсистема обмена сигналами (см. Legal registry) |
| Wangiri / toll fraud | Схемы мошеннического тарифицируемого трафика |
| FP / FN | Ложное срабатывание / пропуск фрода |
| Маркировка | Пометка иностранных/подозрительных вызовов (уточнять у Legal) |

---

## 6. Anti-features (MVP)

- «Лучший в мире ML-антифрод с нуля» вместо соответствия + конфигурируемых правил  
- Смешение СОРМ и антифрода в одном релизе без RACI  
- Блокировки без апелляции/whitelist для B2B  

---

## 7. Handoff

- **Legal:** вопросы по ВАТС, обязанностям оператора vs агрегатора  
- **Detection:** threat map + FP budget  
- **PM:** gap по продуктам API / SMS / голос / 8-800 / ВАТС / кабинет
