# Глоссарий — Проект Мединеф

## Государство и лицензия

| Термин | Простыми словами |
|--------|------------------|
| **ЕГИСЗ** | Госсистема Минздрава. Клиника обязана туда отдавать сведения. |
| **ФРМО** | Карточка клиники: адреса, филиалы, оборудование. Без актуальной карточки лицензионное требование не закрыто. |
| **ФРМР** | Список врачей клиники в ЕГИСЗ. Каждый врач с нужной специальностью должен быть привязан. |
| **РЭМД** | Реестр электронных меддокументов. Не сама карта, а факт: документ создан, где хранится, подпись целая. |
| **СЭМД** | Сам документ в нужном формате (протокол, эпикриз) для РЭМД. |
| **ИЭМК / ФИЭМК** | Федеральная интегрированная электронная карта: обмен сведениями о визитах и документах. |
| **ПП 852** | Правила лицензирования меддеятельности. Сведения в ЕГИСЗ — лицензионное требование. |
| **323-ФЗ** | Закон об охране здоровья. Врачебная тайна, права пациента, меддокументация. |
| **911н** | Приказ Минздрава: что должна уметь МИС. |
| **947н → 209н** | Правила электронной меддокументации. С **1 сентября 2026** действует **209н** вместо 947н. |

## Программы и подписи

| Термин | Простыми словами |
|--------|------------------|
| **МИС** | Программа клиники: запись, карта, касса, протоколы. |
| **ArchiMed+ / Архимед** | Конкретная МИС для частных клиник. Купить лицензию ≠ пользоваться и сдавать в ЕГИСЗ. |
| **Элита** | Пока неясно: второе ПО, модуль или пакет интегратора. Нужно полное имя из договора. |
| **ЭМК** | Электронная медицинская карта пациента внутри МИС. |
| **УКЭП** | Усиленная квалифицированная электронная подпись — «печать врача» в электронном виде. Без неё СЭМД для государства пустой. |
| **Оператор ИИС** | Посредник, который гоняет документы в ЕГИСЗ, если клиника не подключается сама. |
| **VipNet / защищённый канал** | Шифрованный канал до гос. контура. Часто нужен, чтобы МИС достучалась до ЕГИСЗ. |

## Данные, безопасность, сеть

| Термин | Простыми словами |
|--------|------------------|
| **ПДн** | Персональные данные. У клиники ещё и здоровье — особая категория. |
| **152-ФЗ** | Закон о ПДн: согласия, уведомление Роскомнадзора, хранение в РФ, защита. |
| **ИСПДн** | Система, где крутятся ПДн. МИС клиники — это она. |
| **УЗ-3** | Типичный уровень защищённости небольшой клиники: пароли, роли, антивирус, бэкапы, журналы. |
| **ФСТЭК / приказ 21** | Перечень технических мер защиты ПДн. Не «аттестация всем», но меры — да. |
| **Локализация инцидента** | Дыру закрыли. Это ещё не «уведомили РКН» и не «сеть в порядке». |
| **Уведомление РКН 24 часа** | При утечке оператор обязан быстро сообщить Роскомнадзору. |
| **VPN site-to-site** | Постоянный защищённый тоннель между площадками (СПб ↔ Кириши). |
| **VLAN / сегментация** | Развести сети: врачи, гости Wi‑Fi, камеры, оборудование. |
| **RDP наружу** | Удалённый рабочий стол в интернет. Частая причина взлома. |
| **Бэкап** | Копия базы МИС, с которой можно поднять клинику. Не на том же диске, что рабочая база. |
