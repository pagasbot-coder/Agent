## Открытый вопрос Human: сводка директора

Боль директора (Мединеф и Кириши): видеть **сводку** — день / месяц, выручка итогом, по специалистам и доходам — и проваливаться в деталь только если сам захотел. Не менять МИС.

**Вопрос не «пользуются ли отчётами».** Вопрос: Архимед это уже умеет, или данные надо вытаскивать и делать отдельные доски.

Три пути (решение после демо на их базе, не со слайда):

| Путь | Что это | Когда |
|------|---------|--------|
| **1. Из коробки** | Модуль «Отчёты» + web-отчётность: выручка за период, выручка по специалисту, кассовые смены, отчёты по врачам и ЗП, фильтр по дате/врачу, с телефона. Вендор обещает ~80 типовых отчётов и заказ индивидуальных, *если данные уже вводятся в программу*. | Сначала проверить на лицензии Мединеф: модуль есть, web включён, директор видит день/месяц/врач без лабиринта. |
| **2. Доработка у вендора** | Индивидуальный отчёт / экран внутри Архимеда. Данные не покидают МИС. | Почти то, что надо, но нет одной сводки «как директор привык». |
| **3. Доски поверх** | API ArchiMed+ (JWT, Api Id/Secret у вендора) или выгрузка → Metabase / Power BI / своя доска. На маркетинговом сайте API ещё помечали «в разработке» — ключи и состав методов для этой клиники неизвестны. | Директору нужен один визуальный экран с провалом, а список отчётов Архимеда его не закрывает. Это уже второй контур ПДн: после взлома не делать вслепую. |

Пока касса и врачи не бьют данные каждый день, любой путь врёт. Сначала рабочий Архимед, потом выбор 1 → 2 → 3.

После рабочего контура в Мединеф тот же выбор (нативный отчёт vs доска) можно класть в пакет для других клиник. Не раньше.
