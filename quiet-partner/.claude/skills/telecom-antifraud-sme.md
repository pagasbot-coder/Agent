# Skill: Telecom Antifraud SME (Проект МТС)

## Когда применять

Role: SME на задачах Exolve / ГИС «Антифрод» / ВАТС / CLI / ложные блокировки.

## Метод

1. **Глоссарий** — термины поля (RU): CLI, ВАТС, транзитный трафик, 8-800, wangiri, toll fraud, FP/FN.
2. **Day-in-life** — 2–3 персоны: антифрод-аналитик, B2B support, сетевой/телефония.
3. **Hidden pains** — ложные блокировки легальных клиентов, задержка сигнала, путаница СОРМ vs антифрод.
4. **MUST KPI (прокси)** — FP rate, time-to-block, uptime узла обмена (совместно DevOps), доля покрытых продуктов.
5. **Anti-features** — что не тащить в MVP (полный ML с нуля, смешение СОРМ).
6. **Critique** — любая фича PM → «на поле работает / нет, потому что…».
