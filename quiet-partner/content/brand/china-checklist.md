# Чеклист Китай → РФ (этапы 2 / 4)

Канон: [`../../knowledge-base/china-russia-logistics.md`](../../knowledge-base/china-russia-logistics.md)  
В пульте Natural: раздел L + глоссарий ВЭД в primer v1.14.

## Перед оффером (этап 2)

- [ ] Origin зафиксирован (свой завод / Китай / вместе) — иначе не говорим «российское»
- [ ] Метод и минимум % натуральности согласованы с технологом (или статус «открыто»)
- [ ] Пакет бумаг завода: что есть / чего нет (не обещать COSMOS «с полки»)
- [ ] COGS / инкотермс — черновик или явно «открыто»

## На исполнении (этап 4)

- [ ] Спека партии = этикетка = КП (без расхождений)
- [ ] Образец прошёл слепой/гостевой тест до масштаба
- [ ] Риски «Natural без бумаг» и «состав не тянет» — владелец + статус в Р-11
- [ ] Логистика: кто импортёр, кто платит пошлину, lead time

> В UI `/brand` эти пункты — шпаргалка. Факт ведётся в реестрах «Не знаем» / «Риски» / «Решения».
