# Правила: реестры пульта → suggested domain scores

**Роль:** Senior PM · **T-105** · ревизия **T-115** · 2026-07-22  
**Код:** `lib/stages/suggestScores.ts`  
**Disclaimer:** suggested ≠ audit / ≠ PMI cert — co-pilot подсказка после явного «Подтянуть».

## Принцип (анти-Goodhart)

**Фиксировать риски и «не знаем» — хорошо.** Штраф только за *неуправляемое* открытое; работа со статусами `снижен` / `закрыт` / `принят` даёт плюс. Пустой реестр рисков на поздних этапах — минус (прячут риски ради «красивой» статистики).

## Baseline

Стартовые скоры: **62** по всем доменам (янтарь), затем дельты, clamp **15…95**.

## Как работать с Неопределённостью (D8)

1. Записывай риски — сам факт строки **не** наказывает.  
2. На каждый `открыт` с влиянием В заполни **меру до события**.  
3. Когда работаешь с риском → `снижен`; когда миновал → `закрыт`; живёте осознанно → `принят`.  
4. «Не знаем»: закрыл ответ → статус `закрыт` + «Закрыто чем» (штраф снимается).  
5. Снова **«Подтянуть в напарника»**.
