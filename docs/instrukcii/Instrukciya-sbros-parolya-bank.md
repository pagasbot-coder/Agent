# Как сбросить пароль в личном кабинете оценка.рф

Краткая инструкция для сотрудников банка (партнёров). Клиентам этот сценарий не нужен: они входят по SMS-коду.

## Когда это нужно

- Забыли пароль от кабинета.
- Ссылка из приглашения или письма уже не работает (устарела или использована).

Новую ссылку можно получить сами, без обращения в поддержку. Письмо приходит на корпоративную почту, с которой вы входите.

## Вариант 1. С экрана входа

1. Откройте вход банка в личный кабинет оценка.рф.
2. Под формой нажмите **«Забыли пароль?»**.
3. Укажите корпоративную почту, с которой входите, и нажмите **«Сбросить пароль»**.
4. Откройте почту. Тема письма: «Новая ссылка для входа в кабинет оценка.рф». Если письма нет несколько минут, загляните в **«Спам»**.
5. В письме нажмите **«Задать пароль»** (ссылка одноразовая, действует 3 дня).
6. Введите новый пароль дважды и нажмите **«Сохранить пароль»**.
7. Вернётесь на вход. Должно появиться сообщение: «Пароль установлен. Войдите с новым паролем.» Войдите с новой парой почта + пароль.

## Вариант 2. Если ссылка уже устарела

1. Откройте старую ссылку из приглашения или прошлого письма.
2. На экране «Ссылка устарела» нажмите **«Сбросить пароль»** (кнопка выше «Написать в поддержку»).
3. Почту вводить снова не нужно: кабинет отправит новое письмо на вашу почту.
4. Дальше как в варианте 1: письмо → «Задать пароль» → сохранить → войти.

## Важно

- Письмо можно запросить не чаще **одного раза в минуту**. Если нажали слишком часто, подождите минуту и повторите.
- Сценарий только для сотрудников партнёров (банк, МФЦ). Клиенты входят по SMS, пароль им не нужен.
- Если письма нет и в «Спаме» пусто, нажмите **«Написать в поддержку»** на том же экране.
